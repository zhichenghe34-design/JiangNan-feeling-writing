# Jiangnan Feeling Writing

Version: v1.0 skill build.

Use this skill to create or revise original fiction with a Jiangnan-inspired emotional posture and cross-series penwork logic. Build from the person-engine first, choose the right stage/configuration, then apply page-level prose mechanics.

Do not rely on Longzu names, canon events, iconic props, source plots, or copied sentence patterns. Treat all source works as internal craft evidence only.

## Source Discipline

- Final output must be original and contain zero copyrighted fiction excerpts.
- Use paraphrased craft rules only.
- Do not create source-like continuations or claim official Jiangnan/Longzu status.
- Separate evidence, interpretation, and inference when explaining a rule.
- If the user asks for source-text analysis, follow `references/safety-and-boundary.md`.

## Operating Model

Use four axes before writing:

1. **Stage axis**: P1 campus/early wuxia, P2 Jiuzhou epic, P3 urban transition, P4 Longzu startup, P5 Longzu peak, P6 Longzu-late or Tianzhichi-commercial, root-myth branch.
2. **Topic/register axis**: campus, wuxia/epic, urban hot, urban cold, root myth, commercial fantasy. This chooses narrative voice; voice is not simply a time-period marker.
3. **Configuration axis**: Longzu-style emotion-max, Tianzhichi-style commercial-max, Jiuzhou-style epic-distance, P1 warm campus, P3 cold political, etc.
4. **Fingerprint-depth axis**: four innate fingerprints always first; two later-systematized tools only when suited; stage-specific devices only in their own preset.

The four innate fingerprints are the first priority:

- object/action replaces direct psychology
- dialogue carries subtext
- big-topic-small-treatment and small-topic-big-treatment alternate
- paragraph-end afterpain

The two later-systematized tools are optional:

- metaphor scale-up that returns to human cost
- double reading / semantic double-coding

## Workflow

Use this order for writing, diagnosis, or revision:

1. Diagnose the task: create, revise, outline, or evaluate.
2. Build the person and wound: lack, mask, door, belief, cost.
3. Choose topic/register line: campus/urban hot, epic, urban cold, root myth, or commercial fantasy.
4. Choose one stage/config preset from `references/longzu-evolution.md`.
5. Apply the four innate fingerprints.
6. Add later-systematized or stage-specific devices only if the preset allows them.
7. Apply page mechanics from `references/prose-style.md`.
8. Run gates from `references/evaluation-gates.md`.
9. Return the draft/revision plus a concise rationale when useful.

For the full loop, use `references/workflow.md`.

## Output Rules

- Prefer specific actionable revisions over vague praise.
- Keep explanations short unless the user asks for analysis.
- For original prose, write a complete usable scene or passage rather than a list of vibes.
- For revision, preserve the user's premise unless it conflicts with source-safety boundaries.
- For diagnosis, identify which axis/preset/fingerprint is failing and give a concrete repair.

## Hard Failure Modes

Avoid these:

- surface costume: rain, rooftop, loneliness, tragic props, and short sentences without a functional wound
- mean Longzu voice: averaging P5 sweetness, P6 coldness, Jiuzhou epic distance, and prequel history into one fake style
- overusing banter: treating P4 Longzu jokes as cross-topic Jiangnan essence
- wrong P6: treating Longzu IV cold absence as all late Jiangnan
- wrong epic voice: using Jiuzhou historian distance for modern urban intimacy
- fake profundity: metaphor scale-up that never returns to a human cost
- direct emotion dump: naming the feeling instead of making action, object, dialogue, rhythm, or silence carry it
