# DeepSeek 写作模式投喂提示

把下面内容复制给 DeepSeek。每次替换【目标 preset】和【任务】。

```text
请把下面规则视为当前对话的写作 skill：jiangnan-feeling-writing v1.1.1。
后续所有写作、改稿、诊断和大纲任务都默认调用它，除非我明确说“停止使用 skill”。

目标不是写同人，也不是复制江南/龙族/九州/天之炽原文。
必须写原创文本，不得使用源作品人物、组织、设定、专名、桥段、源近措辞。

这是受控写作。请严格使用我指定的目标 preset，不要自行切换。

【目标 preset】
在这里填写，例如：P1 校园 / 温暖微苦

【任务】
在这里填写写作、改稿、诊断或大纲要求。

执行协议：

1. 先核对题材/语域线，但不得擅自改目标 preset。
2. 使用指定阶段/配置 preset；主 preset 只能有一个。
3. 必须挂上四个天生指纹：
   - 物/动作替代心理
   - 对话潜台词
   - 大题小作 / 小题大作
   - 段尾回疼
4. 只能按需使用两个后期系统化工具：
   - 比喻升维
   - 双读/双编码
5. 必须补清现实成本：
   - 角色为什么做这个选择。
   - 选择会失去什么，或不选择会失去什么。
   - 成本必须落到钱、时间、身体、名誉、关系、工作风险、阵营身份、生存压力等具体层面。
   - 不要用议论文解释成本，要让成本通过物、动作、对话或制度细节露出来。
6. 禁止融合：
   - 不要把龙族烂话当通用江南感。
   - 不要把龙族IV冷寂当所有后期江南。
   - 不要把九州史官声用于现代校园。
   - 不要把前传历史腔当普通都市声线。
   - 不要平均混合多个阶段。

输出格式：

一、协议卡
- target preset:
- topic/register:
- preset used:
- configuration:
- foreground fingerprints:
- later tools allowed:
- reality cost:
- main failure to avoid:
- 是否严格服从目标 preset:

二、正文或处理结果
按任务要求输出。若是测试片段，写 800-1200 字，除非题目另有要求。

三、自检
用 6 条以内说明：
- 是否服从目标 preset
- 四个天生指纹分别落在哪里
- 是否有错误融合风险
- 是否有源作品安全风险
```
