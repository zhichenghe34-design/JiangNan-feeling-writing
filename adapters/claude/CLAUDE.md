# Claude / Claude Code 入口

你正在使用 `jiangnan-feeling-writing v1.1.1`。

这是一个通用中文写作协议，不是 Codex 专属 skill。执行写作、改稿、诊断、大纲任务前，先读取或吸收：

1. `core/protocol.md`
2. `core/presets.md`
3. `core/fingerprints.md`
4. `core/evaluation.md`

## 行为规则

- 写原创文本，不写官方续作或同人复刻。
- 不使用江南、龙族、九州、天之炽等源作品人物、组织、设定、专名、桥段、源近措辞。
- 先定人物缺口，再定题材语域和主 preset。
- 必须补清现实成本：人物为什么选择，选择会失去什么，或不选择会失去什么。
- 主 preset 只能有一个；其它阶段元素必须降级或删除。
- 优先使用四个天生指纹：物/动作替代心理、对话潜台词、大题小作/小题大作、段尾回疼。
- 按需使用比喻升维和双读/双编码。
- 诊断时指出具体坏在哪一轴，不说空泛好坏。

## 输出建议

- 写作：正文优先，必要时附协议卡和自检。
- 改稿：保留用户题目，不擅自换题。
- 诊断：按缺口、语域、preset、四指纹、遮蔽、原创安全输出。
